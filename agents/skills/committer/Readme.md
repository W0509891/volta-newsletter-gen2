# Committer Skill

```yaml
name: Committer
description: This skill shows the agent how to write commit changes to a Git repository.
```

## Usage

### GROUP AND COMMIT THE FILES BY SIMILARITY IN CHANGES. Avoid overly verbose descriptions or unnecessary details. Follow the format below, where cat. is one of [refactor., fix., feat., docs., test., build., etc..]                    
```text
\[cat.\] - Summary
DETAILS IF NECESSARY 
```
