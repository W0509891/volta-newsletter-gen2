Volta MCP Service Relationships

A service topology showing which Volta components own authentication, MCP transport, business rules, persistence, rendering, publishing, and external delivery.

Reading the map Solid arrows are runtime calls. Dashed arrows are discovery or credential relationships. Subgraphs represent ownership and trust boundaries, not a time sequence.
